# Капитал — продающий HTML для Tilda

**Единственный актуальный исходник:** [kapital-7k.html](./kapital-7k.html).

Изображения пяти экранов приложения в телефонных рамках (включая повтор «Главной» на первом экране лендинга) находятся в `assets/tilda-v93/screens/`. Формат WebP, 600 × 1120 px. Публичный экран «Ещё» содержит обезличенный демонстрационный аккаунт без личной почты.

Секция «Пять экранов» и блок финансовых показателей обновлены по предоставленным скриншотам приложения за ноябрь 2026 года. Это **демонстрационные, статические значения**, а не автоматическая синхронизация с чьими-либо счетами. Линия над суммами в карточках демонстрации удалена.

**Публикация:** в Tilda открой блок T123 (HTML-код), замени его содержимое файлом `kapital-7k.html` и опубликуй страницу. Одно слияние PR на GitHub **не обновляет** уже опубликованный блок Tilda. Новые фотографии загружаются по CDN-ссылкам `@master/assets/tilda-v93/screens/`; старые v92 используются как аварийный резерв.

Стили и скрипты: `assets/kapital-*.css`, `assets/tilda-v90/kapital-v90-inline.css`, `assets/tilda-v90/kapital-v90-inline.js`.

Цена и платежная ссылка остаются неизменными: 7 000 ₽, один платеж.

Проверка: `node scripts/verify-landing-v93.mjs`.
