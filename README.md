# Капитал — HTML лендинга для Tilda

**Актуальный исходник:** [kapital-7k.html](./kapital-7k.html).

Пять экранов приложения в рамках телефонов находятся в `assets/tilda-v94/screens/` (WebP, 600 × 1120 px). Значок VPN удалён из всех пяти изображений; время, Wi-Fi, сигнал и заряд батареи сохранены. На публичном экране «Ещё» личные данные заменены на «Демо-аккаунт».

Для обратной совместимости изображения `assets/tilda-v93/screens/` также обновлены до версий без VPN. CDN может сохранять старые изображения в кэше; актуальный HTML использует новый путь v94. Резервные ссылки на картинки направлены на raw.githubusercontent.com, также на v94 без VPN.

Секция «Пять экранов» и блок финансовых показателей отражают демонстрационные данные ноября 2026 года. Они **статические**, не синхронизируются со счетами. Линия над суммами удалена; цена 7 000 ₽ и платёжная ссылка не изменены.

**Публикация:** замени содержимое HTML-блока T123 в Tilda текстом из `kapital-7k.html` и опубликуй страницу. Слияние PR на GitHub **не публикует** страницу Tilda.

Стили и скрипты: `assets/kapital-*.css`, `assets/tilda-v90/kapital-v90-inline.css`, `assets/tilda-v90/kapital-v90-inline.js`.

**Проверка:** `node scripts/verify-landing-v94.mjs`, в том числе SHA-256 десяти WebP (новые v94 и обновлённые v93).
