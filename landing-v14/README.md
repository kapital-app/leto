# Капитал Landing v14

Полный ребрендинг оболочки лендинга `lichnye-finansy.ru` без изменения ядра позиционирования продукта.

## Что изменено

- новый premium-fintech visual language: graphite/forest/ivory + acid accent;
- hero строится вокруг решения, а не списка функций;
- 4 разные финансовые цифры разведены визуально сразу на первом экране;
- реальные экраны продукта собраны в интерактивный product showcase;
- функции перепакованы в сценарии решений;
- доверие строится на конкретных механизмах хранения/серверной логики, без маркетинговых обещаний;
- один сильный price block вместо повторяющихся CTA;
- mobile-first responsive layout и reduced-motion support;
- без внешних JS-библиотек.

## Запуск

Открой `index.html` в браузере или подними любой static server.

Изображения экранов загружаются из существующего публичного репозитория `kapital-app/leto` через jsDelivr и зафиксированы на commit `8270db31d19010daa2c7b7c64ad58c4fb484d120`.
